## What this is

The authoring project behind Patterson's design system: design tokens, a small component
library with usage prompts, brand guideline reference cards, framework integrations
(Tailwind, UnoCSS, shadcn, theme-ui), and page/deck/site templates. This site republishes
that project as documentation — the [design guide](/design/) carries the full system
rationale, the [tokens reference](/tokens/) is generated straight from the token
stylesheets, and [components](/components/), [icons](/icons/), and [specimens](/specimens/)
render the rest live.

## Layout

| Path | What it is |
|---|---|
| `tokens/` | Design tokens: base, colors, effects, fonts, icons, spacing, typography |
| `components/` | `core/`, `feedback/`, `forms/` — each ships a `.jsx`, `.d.ts`, and a `.prompt.md` |
| `guidelines/` | Brand reference cards (`.card.html`) — logo, icons, palette, type, interaction states |
| `integrations/` | Tailwind, UnoCSS, shadcn, theme-ui adapters |
| `templates/` | Page/deck/site scaffolds — canvas, corporate page, corporate website, deck, docs site, executive deck, file manager, purpose/vision/values, storefront, tutorialkit |
| `site/` | The design system's own documentation and demo site (this site, plus the legacy static kitchen sink) |
| `DESIGN.md`, `SKILL.md`, `CLAUDE.md` | System rationale, skill invocation, agent conventions |
